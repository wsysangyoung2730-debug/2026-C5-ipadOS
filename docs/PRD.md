# Talk Arena PRD

## 한 줄 정의

AI와 함께 갈등·설득·협업 상황을 게임처럼 시뮬레이션하며, 선택지 기반 챌린지와 음성 기반 현실 리허설을 제공하는 iPadOS 대화 연습 앱입니다.

## 제품 목표

학생이 면접, 설득, 피드백, 협상, 팀플 갈등 등 현실적인 대화 상황을 안전하게 반복 연습하도록 지원합니다.

Challenge Mode에서는 선택지 기반 게임 플레이와 점수 경쟁을 통해 대화 전략을 익히고, Practice Mode에서는 사용자가 직접 설정한 상황을 음성 대화로 리허설하며 구체적인 개선점과 대안 표현을 얻도록 합니다.

## 사용자 문제

학생은 면접, 팀플 갈등, 친구와의 오해, 피드백, 설득 상황에서 어떻게 말해야 할지 몰라 부담을 느낍니다.

실제 상황에서는 실수했을 때 되돌리기 어렵고, 다양한 대응 방식을 비교하며 연습할 기회도 부족합니다.

## 해결 방안

AI가 주어진 상황과 상대 성향에 맞춰 대화 상대를 시뮬레이션합니다.

사용자는 Challenge Mode에서 선택지로 대응하며 점수와 피드백을 받고, Practice Mode에서는 자신의 상황을 설정한 뒤 음성으로 대화하며 개선점과 대안 표현을 제공받습니다.

## 핵심 기능

- 상황 카드 기반 시나리오 제공
- 선택지 기반 턴 진행
- AI 상대 반응 생성
- 턴별 점수와 피드백 표시
- 실제 상황 기반 음성 리허설
- 대화 종료 후 개선점과 대안 표현 제공

## 차별점

- 상담형 챗봇이 아니라 게임형 대화 시뮬레이터로 접근합니다.
- Challenge Mode와 Practice Mode를 분리해 재미와 실용성을 함께 제공합니다.
- iPad의 큰 화면을 활용해 상황, 대화, 선택지, 점수, 피드백을 한 화면에 배치합니다.

## 리스크

- AI가 인간관계를 지나치게 단정하거나 부정확한 조언을 제공할 수 있습니다.
- MBTI 기반 상대 생성이 실제 사람을 고정적으로 판단하는 방식으로 오해될 수 있습니다.
- 음성 인식 품질이나 AI 응답 속도가 낮으면 몰입감이 떨어질 수 있습니다.
- 민감한 대화 데이터를 다루므로 개인정보 보호와 데이터 저장 범위를 신중히 설계해야 합니다.
